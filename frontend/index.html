    Model Analytics

    XGBoost Regressor

    Gradient-boosted trees combine many weak learners into a high-accuracy score predictor.

    Workflow

    Input -> validation -> label encoding -> feature vector -> XGBoost inference -> score response.

    Accuracy Focus

    Model tuned for stability, generalization, and robust performance on mixed categorical + numeric features.

    Why label_encoders.pkl is Required

    label_encoders.pkl stores the same category-to-number mappings used during model training.

    During live prediction, text values like "good", "self-study", or "high" must be converted into exact numeric IDs expected by the trained XGBoost model.

    Without the saved encoders, inference would use inconsistent mappings and predictions could become incorrect.

    Dataset & Training

    Preprocessing

    Clean records, normalize feature types, and encode categorical fields using label encoders.

    Tuning

    Hyperparameters were tuned for better bias-variance balance and improved score prediction quality.

    Why XGBoost

    Excellent for tabular data, handles non-linear patterns, and offers strong performance with engineered features.
